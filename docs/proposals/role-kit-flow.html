2 · The screen index

Designer leads · build-screen-index

Three questions for the designer

Which existing screens does it touch? Extend them or add new ones? Which devices?

↓

AI drafts it from the spec

  • Flows per persona → the screens they stop at → every state of each
  • Every ⚠️ and ❌ example placed, and listed in one table to scan
  • Gaps in the spec become questions for product

What the check says, every time it runs

To fixSomething's missing or broken: a rule with no examples, a screen with no loading state, a tap that points at nothing. The AI fixes it.
Still openListed one by one: unanswered questions, (proposed) items, rules (waiting on …). These need the room.
CompleteNothing to fix, nothing open. "Set status: ready once everyone agrees."
It proves complete and consistent, not good. The review with the room is what makes it right.
