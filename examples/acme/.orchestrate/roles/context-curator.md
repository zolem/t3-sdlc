## Acme conventions

Always read the root `README.md`, `AGENTS.md` (or `CLAUDE.md`) and `docs/architecture.md`. List `docs/` and `docs/patterns/`, and scan the READMEs under `apps/*/src/services/` whose names match the feature's domain.

If an internal wiki tool is available, also fetch the architecture guide and the page for each area the feature touches (auth, data model, public API). Link the pages you used in the context document.
